# Analysis notebooks

The authoritative 18-subject figures are generated by the validated script in
`../figures/`, not by notebooks with hidden state. Add exploratory notebooks
only after the frozen primary matrix exists, keep outputs out of the release,
and preserve subject-level rather than pooled-only analysis. Planned analyses:

1. event duration buckets;
2. modality missingness and timestamp perturbation;
3. read-center/read-width trajectories around event boundaries;
4. latency–accuracy trade-off;
5. subject-macro ablation summaries with participant-bootstrap intervals and
   separately reported model-seed variability.
