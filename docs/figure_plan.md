# EPT2026 short-paper figure and table plan

## 1. Evidence boundary and numbering

This plan is restricted to the frozen
`bci_subjects_ept_v6_marlin4060_aligned11` artifact. Formal figures read
measured artifacts only; demo exports under `fig/_demo/` are layout checks and
are never paper evidence.

The repository and paper use different figure identifiers:

| Paper item | Repository source | Role |
|---|---|---|
| Figure 1 | existing main figure, revised to the contract below | dataset, annotation, task, compact reference model |
| Figure 2 | `fig/fig04_dynamic_tracking/` | dynamic probability and temporal localization trace |
| Figure 3 | `fig/fig05_modality_evidence/` | exploratory Full-versus-Video comparison with true unmatched seed labels |
| Table 1 | frozen metadata, manifests, and preflight report | dataset and protocol audit |
| Table 2 | formal per-seed metrics and aggregates | main quantitative evidence |

The immutable event semantics are:

\[
p_{\mathrm{event}}(t)=P(y_t=0),
\qquad 0=\text{deception},\quad 1=\text{truth}.
\]

Use **target-event probability** in axes and captions. Define the repository
class mapping once in Figure 1/Table 1 rather than repeatedly foregrounding
deception detection.

## 2. Figure 1 -- Multimodal BCI data, annotation, and task

### Scientific job

Figure 1 must make the paper recognizable as a multimodal BCI/data-and-task
paper before the reader sees the architecture. The existing main figure should
be revised so that acquisition, temporal alignment, and event annotation occupy
roughly two thirds of the visual area; the method should be a compact reference
realization on the right.

### Recommended four-panel composition

#### a. Brain--body--behavior acquisition

- Place the participant at the center.
- Show EEG as central neural evidence, PPG as peripheral physiological evidence,
  and video as behavioral evidence.
- Use one canonical color per modality throughout the paper.
- Use a schematic or a fully de-identified frame; do not expose participant
  identity.
- Label the resource as the frozen aligned EEG--PPG--video cohort.

#### b. Shared timeline and post-event grounding

- Draw synchronized EEG, PPG, and video streams on one horizontal time axis.
- Show a post-event record/detail annotation mapped to a target interval
  \([t_s,t_e]\).
- Distinguish target-valid steps from contextual/non-target steps.
- Keep timing and event semantics visually primary; raw-device brand details
  belong in Table 1 or the supplement.

#### c. Temporal task definition

- Input: causal multimodal prefixes up to time \(t\).
- Output: \(p_{\mathrm{event}}(t)=P(y_t=0)\), start probability, end
  probability, and a localized interval.
- Contrast this with one crossed-out or visually minimized session-level label.
  The contrast should communicate the task shift without turning the figure
  into a criticism of binary classification.

#### d. Compact EPT-Net realization

- Show modality encoders, adaptive physiological reading, persistent causal
  fusion, and the probability/boundary heads.
- Do not draw every layer, dimension, loss term, or training stage.
- The method panel should explain how the temporal outputs are obtained, not
  compete with the dataset/task story for visual dominance.

### Required data provenance

- cohort identity and split: frozen manifests and preflight JSON;
- feature families: `configs/eptnet_marlin11_eeg_ppg_video.yaml`;
- class direction: `evaluation.positive_class: 0`;
- annotation/timeline fields: frozen dataset metadata and the same target-mask
  contract used by training and evaluation.

### Caption template

> **Figure 1. Continuous multimodal BCI event recognition.** EEG, PPG-derived
> physiology, and video are aligned on a common timeline in the frozen
> multimodal cohort. Post-event records define time-localized target
> intervals. Given causal multimodal evidence, EPT-Net estimates the target-event
> probability \(P(y_t=0)\), boundary evidence, and localized intervals; the
> repository retains the annotation encoding `0=deception, 1=truth`.

### Primary-source visual precedents

- synchronized EEG/PPG/video samples and experimental timing:
  [Yang et al., Scientific Data 2024](https://www.nature.com/articles/s41597-024-03676-4);
- a multi-device BCI flowchart with a common time base:
  [Guttmann-Flury et al., Scientific Data 2025](https://www.nature.com/articles/s41597-025-04861-9);
- recent EEG--cardiac--video dataset organization and technical validation:
  [Kashevnik et al., Scientific Data 2026](https://www.nature.com/articles/s41597-026-07209-z);
- interval/action/description annotation overview:
  [EgoExoLearn, CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/html/Huang_EgoExoLearn_A_Dataset_for_Bridging_Asynchronous_Ego-_and_Exo-centric_View_CVPR_2024_paper.html).

## 3. Figure 2 -- Dynamic probability and localization trace

### Repository mapping

Paper Figure 2 is generated by
`fig/fig04_dynamic_tracking/plot_fig04_dynamic_tracking.py`. Its authoritative
contract is `fig/fig04_dynamic_tracking/figure.yaml` and
`fig/FIGURE_CONTRACTS.md`.

### Scientific job

Show, on one predeclared held-out sequence, that the model output is a temporal
probability process connected to explicit event boundaries and intervals. This
figure explains *what the model recognizes over time*; it is not a substitute
for aggregate metrics.

### Four vertically aligned panels

1. **Localized intervals:** ground-truth intervals, decoded intervals, and
   non-target/context spans.
2. **Target-event probability:** `positive_probability`, labelled
   \(P(y_t=0)\), with the validation-selected frame threshold.
3. **Boundary evidence:** start and end `boundary_probabilities`, with reference
   onset/offset positions.
4. **Adaptive reads:** `read_centers` and `read_widths` for EEG time, EEG
   spectrum, and PPG-derived physiology. Centers and widths are normalized cache
   coordinates, not seconds.

Use one shared time axis. Do not smooth, impute, hand-edit, or rescale a trace
to make the event visually cleaner.

### Formal input contract

Use matching files from one full EPT-Net run:

```text
results/eptnet_marlin11_eeg_ppg_video_no_text/seed_13/
  test_predictions.jsonl
  test_events.json
  test_metrics.json
```

Each selected prediction row must contain:

```text
sample_id, row_index, positive_class, target_valid,
positive_probability, boundary_probabilities,
read_centers, read_widths
```

`start_time_seconds` and `end_time_seconds` may be used only if available for
every plotted step. Event lists must follow the same first-appearance sequence
order as the prediction JSONL.

### Sample-selection safeguard

Before rendering formal predictions, save the selected `sample_id` and rule in
the experiment record. Recommended rule:

> Select the first test-manifest sequence containing at least one annotated
> target event, using ground truth only and before inspecting prediction curves.

A preregistered median-performance rule is also acceptable, but the rule must
be fixed before visual inspection and implemented automatically. Never browse
plots and then choose the most attractive trace.

### Visual encoding

Follow the checked-in ResearchPilot color contract:

- event probability: dark blue;
- reference interval: coral;
- decoded interval: blue;
- start boundary: teal;
- end boundary: orange;
- EEG-time reader: blue;
- EEG-spectrum reader: purple;
- PPG reader: teal;
- invalid/non-target interval: neutral grey.

### Caption template

> **Figure 2. Continuous target-event recognition and localization on a
> predeclared held-out sequence.** The model outputs \(P(y_t=0)\) at every
> target-valid step and decodes intervals with the validation-selected
> threshold. Start/end evidence and modality-specific reader trajectories show
> how event localization and physiological context evolve on the same causal
> timeline. The displayed sequence was selected by **[predeclared rule]**.

### Primary-source visual precedents

- per-time class score plus onset/offset distributions:
  [ActionFormer, ECCV 2022](https://www.ecva.net/papers/eccv_2022/papers_ECCV/html/7278_ECCV_2022_paper.php);
- relative boundary response visualization:
  [TriDet, CVPR 2023](https://openaccess.thecvf.com/content/CVPR2023/html/Shi_TriDet_Temporal_Action_Detection_With_Relative_Boundary_Modeling_CVPR_2023_paper.html);
- online prediction/progress timelines:
  [Progress-Aware Online Action Segmentation, CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/html/Shen_Progress-Aware_Online_Action_Segmentation_for_Egocentric_Procedural_Task_Videos_CVPR_2024_paper.html);
- predicted-versus-reference events with frame/event/latency evaluation:
  [Context-Enhanced Memory-Refined Transformer, CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/html/Pang_Context-Enhanced_Memory-Refined_Transformer_for_Online_Action_Detection_CVPR_2025_paper.html).

## 7. Optional supplemental reliability diagram

The 4--6 page main paper should keep Brier and NLL in Table 2. Add a reliability
diagram only if space remains or place it in the supplement.

### Minimum valid design

- use the class-0 target-event probability on target-valid held-out steps;
- use 8--10 equal-frequency bins and display bin counts;
- plot empirical target-event frequency against mean predicted probability;
- report Brier, NLL, and ECE together;
- state the binning rule and resampling unit in the caption;
- account for temporal dependence by resampling subjects or complete
  sequences, never individual frames, if uncertainty bands are shown.

Raw model scores should be called a **probability trajectory** or
**probability output**, not a calibrated probability. If temperature scaling is
added later, fit its temperature on validation outputs only, freeze it, and
evaluate it on held-out data. Show raw and adjusted curves and save the fitted
temperature plus its provenance.

The standard reliability-diagram precedent is
[Guo et al., ICML 2017](https://proceedings.mlr.press/v70/guo17a.html).
[Chidambaram et al., ICML 2024](https://proceedings.mlr.press/v235/chidambaram24a.html)
shows why ECE is bin-sensitive and should not be the sole probability-quality
claim.

## 8. Compact-paper placement

For a six-page main text:

- page 1: Figure 1 under the opening contribution statement;
- page 2: Table 1 beside Task/Data;
- pages 3--4: compact method followed by Table 2;
- page 5: full-width Figure 2;
- page 6: Figure 3, discussion/conclusion, and optional supplementary diagnostics.

For four pages, keep the core evidence objects but make Figure 1 shallow, place
Table 1 as a compact single-column table, reduce Table 2 to five principal
metrics, and move the reliability plot and mechanism diagnostics to the
supplement. Do not remove Figure 2: it is the clearest visual proof that the
task is dynamic rather than a simple binary classifier.
